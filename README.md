# 📘 Interactive Smart-Board Teaching Web App — Lesson 1
## Development of Information Technology & Social Transformation
### تطور تكنولوجيا المعلومات والتحول الاجتماعي

An interactive, touch-friendly smart-board educational web application built for secondary school students (2nd Sec) covering the history, core milestones, social impacts, and modern emerging technologies of computing.

---

## ✨ Key Features

- **🌐 Dual-Language Support (`EN | عربي`)**: Instant language toggle switching all texts, cards, and diagrams between English and Arabic with full RTL support.
- **⏳ Interactive Timeline (1940s to Present)**: Step-by-step progressive reveal of major computing eras (ENIAC, Personal Computers, Internet, Smartphones, Cloud Computing).
- **📈 Animated Moore's Law Simulator**: Logarithmic scale chart tracking transistor growth from Intel 4004 (2,300) to Apple M1 Ultra (114 billion) with physical limit analysis.
- **🌍 5 Pillars of Social Transformation**: Cause-effect chains for SNS, E-commerce, Remote Work, Online Learning, and Cashless Payments.
- **🚀 Emerging Tech Explorer**: Deep dives into Autonomous Driving, Edge Computing, AR vs. VR, and Classical Bit vs. Qubit Superposition.
- **⚖️ Dedicated Comparisons**: Side-by-side comparison cards (Cloud vs. Edge, AR vs. VR).
- **💡 "توقف وفكر" & "معلومة مهمة"**: Interactive textbook-styled pedagogical callouts.
- **📝 Exam Preparation & Assessment**: Worked examples, try-it drills, and an exam-style 6-mark essay question breakdown with hints and model answers.
- **👨‍🏫 Teacher Toolbar**: Fullscreen Classroom Mode, Teacher Talking Notes toggle, section jump menu, and animation controls.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router + Turbopack)
- **Language**: TypeScript & React 19
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design System
- **Animations**: Framer Motion
- **State Management**: Zustand
- **Typography**: Inter, Space Grotesk & Noto Sans Arabic

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
